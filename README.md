Sobre o jogo
Lorenzo Magnus é um jogo 2D feito em Python com Pygame onde o objetivo é escapar de uma masmorra antes que o tempo acabe. O jogo passa por três fases seguidas, com um cronômetro geral e um ranking:

1. Labirinto: fuja do inimigo que te persegue pelo mapa e colete dinheiro até chegar na porta do parkour.
2. Parkour: atravesse as plataformas desviando dos inimigos com 3 vidas até alcançar a porta final.
3. A Porta: clique na porta para quebrar ela antes do tempo zerar e conseguir escapar. Use o dinheiro coletado nas fases para comprar upgrades de dano e o Auto-Chute faz 10 cliques por segundo sem você precisar clicar na porta.

Dificuldades:
- Fácil: 2 minutos de limite, 3 inimigos no parkour, porta com 500 de vida.
- Média: 2:30 minutos de limite, 6 inimigos no parkour, porta com 2000 de vida.
- Difícil: 3:15 minutos de limite, 10 inimigos no parkour, porta com 10000 de vida.

Controles
- Labirinto: W, A, S, D ou as setas do teclado.
- Parkour: A/D (ou as setas) para andar; W, Espaço ou a seta para cima para pular.
- Fase da Porta: clique esquerdo do mouse para bater na porta e comprar upgrades na loja.

Como rodar o jogo
Ter o Python 3 instalado no computador;
Instale o pygame dentro da pasta do projeto (pelo terminal) e abra o jogo:
"pip install pygame";
"python main.py".
